Problem notes

A checklist for recording evidence, assumptions, errors, and the next useful step.

1. Question

State the practical question without including the answer you hope to find.

2. Evidence

List records, measurements, observations, dates, and source quality.

3. Missing information

List variables or records that are not available.

4. Assumptions

Separate measured values from estimates and scenario choices.

5. Methods

Record equations, prompts, scripts, tools, and parameters.

6. Errors and failed attempts

Keep the approaches that failed and explain why.

7. Results

State only what the work supports.

8. Limits

List conclusions the result does not support.

9. Next data

Identify the record, measurement, or test that would reduce uncertainty most.

10. Files

Attach code, configuration, tests, and ordinary export formats where possible.
