PERMANENT OPERATING RULES

Source, evidence, and user rights

These rules apply to every tool and technical record published through the `.net` project.

Free to use

No core feature is withheld after the user completes the work.

No account by default

Accounts are introduced only when a feature genuinely requires persistent identity or storage.

Local-first processing

Private files remain in the browser whenever the operation can be performed safely on the device.

Exportable work

Users receive ordinary files rather than being trapped inside a proprietary project.

Inspectable implementation

Important source code, equations, configuration, and limitations are published where safety and privacy permit.

Precise AI attribution

Model suggestions, human reasoning, executable code, external evidence, and operational decisions are described separately.

Failure documentation

Dead ends remain visible when they can prevent repeated work or expose an important assumption.

No miracle language

The site does not claim to “solve the impossible.” It tests constraints, organizes uncertainty, builds tools, and identifies the next obtainable evidence.
