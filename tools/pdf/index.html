DEVELOPMENT SPECIFICATION

Free, local-first PDF tools

This page is not yet an editor. It publishes the requirements before implementation so the eventual tool cannot quietly drift into uploads, account walls, weak redaction, or hostage downloads.

Initial operations

Merge, split, reorder, rotate, delete, extract, image-to-PDF, page numbering, and loss-aware compression.

Privacy boundary

Document bytes remain on the device for every operation supported safely in the browser. Any future server-side requirement must be disclosed before file selection.

Redaction requirement

True redaction must remove underlying text and image content. Drawing an opaque rectangle over extractable information will never be labeled “redaction.”

Completion rule

The download button remains free after the work is finished. No email address, countdown, account, or payment prompt appears between processing and export.
