WORKING LOCAL BROWSER TOOL

Local PDF Desk

Merge PDFs, extract selected pages, or rotate every page. The files are processed in your browser and are not uploaded by this page.

Privacy boundary: selected document bytes remain on this device. The PDF processing library is loaded from a public CDN when the page opens.
Merge uses every selected file in the order shown by your browser. Extract and rotate use the first selected file.
Page numbers start at 1.

Choose a PDF to begin.

What this version does

It creates new downloadable PDF files by merging complete documents, copying chosen pages into a new document, or applying a page rotation.

What it does not do yet

No compression, annotation, signatures, OCR, page-number stamping, or true content redaction. Those features are not advertised as available.
